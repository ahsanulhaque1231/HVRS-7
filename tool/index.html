QUICK GUIDE

Click. Pick a class. Done.

This is a manual annotation tool. No automatic detections or classifications are used.

1. Point mode

Click an object, then select its class from the menu. Click the colored marker later to change its label, flag it uncertain, or delete it. Drag a point to reposition.

2. Box mode

Drag from one corner of an object to the other, then choose a class. Click any box to edit its label. Drag inside to move. Hold Shift while dragging to create a box inside an existing box.

3. Review

Mark each frame reviewed, including frames with no detectable objects. Notes and unclear status are saved with the frame.

4. Export

Download a JSON backup, point/box CSV, or a ZIP of labeled image copies. Your source JPEGs never change.
